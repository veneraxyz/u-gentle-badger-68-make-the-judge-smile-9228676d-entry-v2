# Make the Judge Smile

[![Competition](https://make.fun/badge/u-gentle-badger-68-make-the-judge-smile-9228676d.svg)](https://make.fun/competitions/u-gentle-badger-68-make-the-judge-smile-9228676d)

[![Reward](https://make.fun/badge/veneraxyz/u-gentle-badger-68-make-the-judge-smile-9228676d-entry-v2/reward.svg)](https://make.fun/competitions/u-gentle-badger-68-make-the-judge-smile-9228676d)

One line, max 200 characters, about a small good thing that happened today — a kindness from an ojek driver on a rainy morning, told with one concrete detail (a rescued earbud) and a small surprise (he waves off the tip and rides away humming like the street is his).

`main.ts` (Node 22, stdlib only) writes exactly that one line to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (falling back to the absolute path `/output`), and exits non-zero if the line is not exactly one line of 1–200 characters.
